circle cacher project

This is my Circle Catcher project, where you use the Left and Right Arrow keys or the A and D keys to move left and right and catch the circle. The more circles you catch, the faster the game becomes, making it increasingly difficult. I made this game in Python using the Turtle library. The project was first started in 2025 and finished in 2026. That is why it was listed as a 2026 project on my old website. However, I now consider it a 2025 project because that is when the original version was created on Trinket. This project helped me improve my understanding of event-driven programming, game loops, and working with user input. If I had to rate the difficulty of making it, I would give it a 5/10. The programming concepts were not extremely difficult, but balancing the gameplay and gradually increasing the speed took some testing. If you would like to try the game, click here.
